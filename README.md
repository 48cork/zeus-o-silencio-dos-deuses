# ZEUS — O Silêncio dos Deuses

Episódio ilustrado: abertura, cinco cenas, diário, escolhas, consequências, epílogos e discussão. Pinturas e conteúdo preservam a ambiguidade das manifestações divinas.

## Execução

Site estático, sem instalação ou compilação. Para uso local, execute `python3 -m http.server 8765 --bind 127.0.0.1` nesta pasta e abra http://127.0.0.1:8765/. Não abra diretamente por file://.

## Progresso

O progresso fica no navegador, por origem; não é enviado a um servidor. A interface permite exportar e importar uma cópia JSON. Mudar do endereço local para o publicado não transfere automaticamente o progresso. As anotações da discussão não são salvas. Este pacote não contém partidas, exportações ou dados de jogadores.

## Imagens e referências

As seis pinturas principais e as três pinturas da introdução aprovadas são apresentadas inteiras, com textos alternativos, descrições e ampliação. As notas históricas e suas ressalvas estão disponíveis no episódio. As imagens são preservadas nos PNGs aprovados, sem versões otimizadas; a interface solicita a imagem da cena atual.

## English edition

Open `en/` on the same site, or use the English link in the Portuguese version. Both editions use the same rules, six approved images, and progress format. After switching language, select Continue saved path / Continuar percurso salvo to resume. Discussion notes are not saved; copy them before leaving the page.

The English edition includes the complete episode, choices, costs, consequences, journal, endings, discussion, image descriptions, and historical caveats. Automated local checks cover all 4,896 complete paths. Real-browser and assistive-technology checks remain pending. The public Portuguese edition was confirmed by the project owner; that confirmation does not automatically validate the English translation.

No continuation or appearance of Zeus has been implemented.
